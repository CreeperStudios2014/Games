# Photorealistic Lemon Clicker

This repository contains a web-based clicker game inspired by "Sell Lemons" on Roblox by Bloxbyte.

What's included:
- index.html — the game page
- style.css — styles
- main.js — game logic (clicking, shop, evolution, investors, ascensions)
- README.md — this file

How to run:
1. Open `index.html` in a browser (modern browsers recommended).
2. The game saves to localStorage.

Notes:
- The game's visuals load high-resolution, photorealistic images from Unsplash.
- I will create a branch named `Lemon-Clicker-Game` and add the game files to it.
